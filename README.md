# denarius – Web3 Strategy City Builder

denarius is a prototype of a city-building strategy game built with Angular + Ionic and integrated with Web3 via Metamask. The game simulates construction, citizens management and on-chain interactions for future NFT/Token logic.

## 🔧 Features

- Dynamic 16x16 grid city
- Construct buildings (e.g. Towncenter, House, Farm...)
- Upgrade buildings and assign Citizens as workers
- Real-time construction progress bar
- Wallet connection using Metamask + Web3.js
- Modular architecture using Angular Components + Services

## ⚙️ Tech Stack

- 🧠 Angular + Ionic
- 🎮 Canvas-style game using CSS Grid
- 💸 Web3.js for blockchain connection
- 🔥 Firebase Hosting (optional)
- TypeScript, SCSS
